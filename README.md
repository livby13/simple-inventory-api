# Simple Inventory RESTful API

Backend API sederhana yang dibuat menggunakan **Node.js**, **Express**, dan **SQLite** untuk mengelola data inventaris produk (mendukung operasi CRUD lengkap).

# Teknologi yang digunakan
- Node.js
- Express.js
- SQLite3

# Fitur API (Endpoints)
1. **GET /products** - Mengambil seluruh data produk.
2. **POST /products** - Menambahkan data produk baru.
3. **PUT /products** - Mengubah data produk berdasarkan ID.
4. **DELETE /products/:id** - Menghapus data produk berdasarkan ID.
